### 2. 💕 **Análisis de Compatibilidad de Pareja**

#### Descripción:
Compara tu firma con la de tu pareja (o crush) para descubrir compatibilidad de personalidades.

#### Flujo de Usuario:

1. **Usuario completa su propio análisis**
2. **Opción en resultados:** "¿Quieres saber si eres compatible con alguien?" (CTA llamativo)
3. **Usuario ingresa firma de la pareja:**
   - Opción A: Envía link de invitación (gamificación social)
   - Opción B: Sube/dibuja firma manualmente
4. **Análisis comparativo se genera en 5-7 segundos**
5. **Resultados de compatibilidad**

#### Contenido del Análisis:

**Score de Compatibilidad Global: 0-100%**
- 90-100%: 💕 "Almas gemelas"
- 75-89%: 💖 "Altamente compatibles"
- 60-74%: 💛 "Buenos prospectos"
- 45-59%: 💙 "Desafíos manejables"
- 0-44%: 💔 "Polos opuestos"

**Secciones:**

1. **Gráfico de Compatibilidad Radar**
   - Compara 8 dimensiones superpuestas
   - Áreas de coincidencia en verde
   - Áreas de diferencia en rojo/amarillo

2. **Dimensiones Analizadas:**
   - **Energía Emocional** (presión del trazo)
   - **Estilo de Comunicación** (legibilidad)
   - **Orientación Temporal** (inclinación)
   - **Nivel de Apertura** (rúbrica)
   - **Estabilidad** (simetría)
   - **Creatividad** (ornamentación)
   - **Liderazgo vs. Seguimiento** (tamaño)
   - **Racionalidad vs. Emocionalidad** (ángulos vs. curvas)

3. **Fortalezas de la Relación** (3-5 puntos)
   - Ejemplo: "Ambos tienen alta energía emocional (presión fuerte), lo que indica pasión compartida"
   - Iconos positivos y descripciones motivadoras

4. **Áreas de Crecimiento** (3-5 puntos)
   - Ejemplo: "Uno es más reservado (rúbrica compleja) y otro más abierto. Comunicación es clave."
   - Consejos constructivos, nunca negativos

5. **Dinámica de la Relación**
   - ¿Quién es más líder?
   - ¿Quién es más emocional?
   - ¿Cómo se complementan?
   - Metáfora de relación (ej: "Fuego y aire - se complementan perfectamente")

6. **Recomendaciones para la Relación**
   - 5 tips personalizados basados en combinación de características
   - Actividades recomendadas juntos
   - Cómo manejar conflictos según personalidades

7. **Comparación con Otras Parejas**
   - "Son más compatibles que el 78% de las parejas analizadas"
   - Ranking anónimo

8. **Opción de Compartir**
   - Generar imagen con score de compatibilidad
   - "Compartimos X% de compatibilidad 💕 #FirmasApp"
   - Stickers/GIFs personalizados para compartir

**Elementos Virales:**
- **Challenge de Parejas:** "¿Cuánto compatibilidad tienen con tu pareja? 💕"
- **Trend TikTok:** Videos de parejas descubriendo su % de compatibilidad (reacciones)
- **Formato shareable:** Imagen cuadrada optimizada para IG/TikTok
- **Gamificación:** "Reto: ¿Pueden llegar a 90% de compatibilidad modificando sus firmas?"

**Tecnología:**
- Algoritmo de comparación de vectores de características
- Weighted scoring basado en importancia de cada dimensión
- Machine learning para mejorar precisión (opcional post-MVP)

### 3. 🎨 **Generador de Firmas con IA (Nano Banana Pro)**

#### Descripción:
Crea una firma personalizada usando IA generativa de Google que refleje cómo quieres ser percibido.

#### ¿Qué es Nano Banana?

**Nano Banana Pro** (oficialmente Gemini 3 Pro Image) es el modelo de generación de imágenes de Google DeepMind, lanzado en agosto 2025 y convertido en sensación viral con más de 10 millones de usuarios en semanas.

**Características:**
- Generación fotorealista de imágenes
- Edición avanzada con instrucciones en lenguaje natural
- Razonamiento de última generación para interpretación de prompts
- API disponible a través de Gemini API

**Fuentes:**
- [Nano Banana Pro - Google DeepMind](https://deepmind.google/models/gemini-image/pro/)
- [Gemini Image Generation API](https://ai.google.dev/gemini-api/docs/image-generation)

#### Flujo de Usuario:

**Paso 1: Cuestionario de Personalidad Deseada**

Pregunta principal: **"¿Cómo quieres que te perciban?"**

Opciones (selección múltiple o sliders):

1. **Profesionalismo:**
   - Serio y confiable ⚖️ ← → Creativo y dinámico 🎨

2. **Energía:**
   - Calmado y reflexivo 🧘 ← → Enérgico y apasionado 🔥

3. **Estilo:**
   - Minimalista y simple ⚪ ← → Elaborado y único ✨

4. **Proyección:**
   - Accesible y cercano 🤝 ← → Exclusivo y distinguido 👑

5. **Innovación:**
   - Tradicional y clásico 📜 ← → Moderno y vanguardista 🚀

6. **Carácter:**
   - Reservado y misterioso 🎭 ← → Abierto y transparente 🌟

**Paso 2: Entrada de Nombre**
- Usuario escribe su nombre completo
- Sistema detecta si prefiere iniciales, nombre corto, etc.

**Paso 3: Preferencias Visuales**
- Estilo de trazo: Manuscrita cursiva / Caligráfica / Moderna / Rúbrica abstracta
- Grosor: Fino / Medio / Grueso
- Inclinación: Recta / Ligeramente inclinada / Muy inclinada
- Elementos decorativos: Subrayados / Rúbricas / Florituras / Minimalista

**Paso 4: Generación con Nano Banana Pro**

**Proceso técnico:**

1. **Construcción del Prompt:**
   ```
   Generate a signature for the name "[Nombre del Usuario]" in handwritten style.

   Characteristics:
   - Professionalism level: [0-100]
   - Energy: [calm/energetic]
   - Style: [minimalist/elaborate]
   - Stroke: [thin/medium/thick]
   - Inclination: [upright/slight/strong forward tilt]
   - Decorative elements: [underline/flourish/abstract rubric/none]

   The signature should convey: [adjetivos basados en personalidad deseada]

   Style: Elegant handwritten signature on white background, black ink,
   professional quality, suitable for documents and personal branding.

   Output: Clean signature with transparent background, high resolution.
   ```

2. **Llamada a Gemini API:**
   ```javascript
   const response = await fetch('https://generativelanguage.googleapis.com/v1/models/gemini-3-pro-image:generateImages', {
     method: 'POST',
     headers: {
       'Content-Type': 'application/json',
       'Authorization': `Bearer ${GEMINI_API_KEY}`
     },
     body: JSON.stringify({
       prompt: constructedPrompt,
       number_of_images: 4, // Generar 4 variaciones
       safety_settings: { /* ... */ }
     })
   });
   ```

3. **Post-procesamiento:**
   - Eliminar fondo si es necesario
   - Ajustar contraste y brillo
   - Redimensionar a formato óptimo (800x300px)
   - Aplicar filtros para consistencia

**Paso 5: Selección y Personalización**

- Usuario ve 4 variaciones generadas
- Puede regenerar con ajustes
- Puede editar manualmente sobre el canvas
- Preview en contextos: documento, tarjeta, email

**Paso 6: Descarga y Uso**

- Descarga en múltiples formatos:
  - PNG transparente (alta resolución)
  - SVG vectorial (escalable)
  - GIF animado (para firmas digitales dinámicas)

- Guías de uso:
  - Cómo practicar la firma en papel
  - Cómo usar en documentos digitales
  - Cómo configurar firma automática en email

**Paso 7: Análisis de la Firma Generada**

- El sistema analiza la firma generada con el mismo algoritmo
- Muestra cómo será percibido por otros
- Confirma que la firma refleja la personalidad deseada
- "Tu nueva firma proyecta: 87% profesionalismo, 92% creatividad..."

#### Elementos Virales:

**TikTok Challenge:**

- Video mostrando antes/después

```javascript
// API Route: /api/generator/create

export async function POST(request) {
  // 1. Verificar autenticación y subscripción Premium
  const user = await authenticate(request);
  if (user.subscription_tier === 'free') {
    return error(403, 'Premium subscription required');
  }

  // 2. Verificar cuota mensual
  const quota = await checkGenerationQuota(user.id);
  if (quota.remaining === 0) {
    return error(429, 'Monthly quota exceeded');
  }

  // 3. Extraer datos del cuestionario
  const { userName, personalityInput, visualPreferences } = await request.json();

  // 4. Construir prompt optimizado para Nano Banana
  const prompt = buildSignaturePrompt(userName, personalityInput, visualPreferences);

  // 5. Llamar a Gemini API (Nano Banana Pro)
  const geminiResponse = await fetch(
    'https://generativelanguage.googleapis.com/v1/models/gemini-3-pro-image:generateImages',
    {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${process.env.GEMINI_API_KEY}`
      },
      body: JSON.stringify({
        prompt: prompt,
        number_of_images: 4,
        aspect_ratio: '16:9',
        safety_settings: { /* ... */ }
      })
    }
  );

  const { images } = await geminiResponse.json();

  // 6. Post-procesar imágenes (eliminar fondo, ajustar)
  const processedImages = await Promise.all(
    images.map(img => processSignatureImage(img))
  );

  // 7. Subir a Cloudinary/S3
  const uploadedUrls = await Promise.all(
    processedImages.map(img => uploadToCloud(img))
  );

  // 8. Guardar en base de datos
  const generatedSignature = await db.generated_signatures.create({
    data: {
      user_id: user.id,
      user_name: userName,
      personality_input: personalityInput,
      generated_images: uploadedUrls,
      generation_count: 1
    }
  });

  // 9. Decrementar cuota
  await decrementQuota(user.id);

  // 10. Analizar la firma generada automáticamente
  const analysis = await analyzeSignature(uploadedUrls[0]);

  // 11. Retornar resultados
  return json({
    id: generatedSignature.id,
    images: uploadedUrls,
    analysis: analysis,
    remaining_quota: quota.remaining - 1
  });
}
```

### Flujo Técnico - Generación de PDF Profesional:

```javascript
// Usar librería: jsPDF + html2canvas

import jsPDF from 'jspdf';
import html2canvas from 'html2canvas';

export async function generateProfessionalReport(analysisId) {
  // 1. Obtener datos completos del análisis
  const analysis = await db.signature_analyses.findUnique({
    where: { id: analysisId },
    include: { user: true }
  });

  // 2. Renderizar HTML template del reporte
  const reportHTML = renderReportTemplate(analysis);

  // 3. Convertir HTML a Canvas
  const canvas = await html2canvas(reportHTML, {
    scale: 2, // Alta resolución
    useCORS: true,
    logging: false
  });

  // 4. Crear PDF
  const pdf = new jsPDF({
    orientation: 'portrait',
    unit: 'mm',
    format: 'a4'
  });

  // 5. Agregar páginas (un reporte tiene ~15 páginas)
  const pageHeight = 295; // A4 height in mm
  const imgWidth = 210; // A4 width in mm

  for (let page = 0; page < 15; page++) {
    if (page > 0) pdf.addPage();

    const pageCanvas = await renderReportPage(analysis, page);
    const imgData = pageCanvas.toDataURL('image/png');

    pdf.addImage(imgData, 'PNG', 0, 0, imgWidth, pageHeight);
  }

  // 6. Generar buffer del PDF
  const pdfBuffer = pdf.output('arraybuffer');

  // 7. Subir a S3/Cloudinary
  const pdfUrl = await uploadPDFToCloud(pdfBuffer, `report-${analysisId}.pdf`);

  // 8. Guardar referencia en DB
  await db.pdf_reports.create({
    data: {
      user_id: analysis.user_id,
      analysis_id: analysisId,
      pdf_url: pdfUrl,
      report_type: 'professional'
    }
  });

  return pdfUrl;
}
```

## 🚨 Riesgos y Mitigaciones

### Riesgos Identificados:

**1. Costos de Nano Banana Pro escalando rápido**
- **Mitigación:**
  - Implementar cuotas mensuales estrictas
  - Considerar modelo híbrido: primeras generaciones con Nano Banana, después con Stable Diffusion
  - Negociar pricing con Google si volumen es alto

**2. Baja conversión Free → Premium**
- **Mitigación:**
  - A/B testing agresivo de paywalls
  - Mejorar diferenciación de features premium
  - Ofrecer "taste" de premium (1 reporte gratis, 1 compatibilidad gratis)

**3. App considerada "frivola" o no seria**
- **Mitigación:**
  - Disclaimer claro: entretenimiento + autoconocimiento
  - Base científica de grafología explicada
  - Colaboración con grafólogos profesionales para validación

**4. Problemas legales (privacidad, datos biométricos)**
- **Mitigación:**
  - Opción de no guardar firma (modo privado)
  - Encriptación de todas las firmas
  - GDPR/LOPD compliance desde día 1
  - Términos y privacidad claros

**5. Competencia de apps similares**
- **Mitigación:**
  - Diferenciador clave: Generador de firmas IA (único)
  - Comunidad y engagement (network effects)
  - Velocidad de ejecución e innovación
